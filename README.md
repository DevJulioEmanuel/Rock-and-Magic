# 🎮 Rock And Magic

**Rock And Magic** é um projeto de jogo desenvolvido como experiência prática de aprendizado em desenvolvimento de games. O jogo segue o estilo **2D Top-Down**, com foco em mecânicas de combate e suporte a multiplayer básico.

---

## 📌 Sobre o Projeto

Este projeto foi criado com o objetivo de explorar o universo de desenvolvimento de jogos utilizando a engine **Godot**. Durante o desenvolvimento, foram implementadas diversas funcionalidades fundamentais para jogos 2D, além de conceitos importantes de programação e arquitetura.

O jogo também foi utilizado como parte de um trabalho acadêmico, onde foi incorporado um sistema de multiplayer.

---

## 🚀 Funcionalidades

- 🎮 Movimentação do personagem  
- ⚔️ Sistema de combate básico (PvP)  
- ❤️ Sistema de vida (health system)  
- 👾 Inimigo básico (ex: slime)  
- 🌐 Multiplayer (implementação inicial)  
- 🎨 Artes e animações autorais  

---

## 🧠 Aprendizados

Durante o desenvolvimento do **Rock And Magic**, foram adquiridos conhecimentos importantes como:

- Estruturação de projetos em jogos 2D  
- Lógica de movimentação e colisão  
- Implementação de sistemas de combate  
- Gerenciamento de estados (vida, ataque, etc.)  
- Conceitos iniciais de multiplayer em jogos  
- Criação de assets (arte e animação)  

---

## 🛠️ Tecnologias Utilizadas

- **Godot Engine**  
- **GDScript**  
- Conceitos de redes para multiplayer  

---

## 🎯 Objetivo

O projeto foi desenvolvido com foco em aprendizado e evolução como desenvolvedor, permitindo explorar na prática conceitos de game development, além de servir como base para projetos futuros mais complexos.
